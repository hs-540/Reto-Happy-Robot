# Project rules

## Language: English only

Everything in this repository is written in **English**. No exceptions.

This applies to:

- **Code**: identifiers (variables, functions, types, interfaces), file and folder names, enum values and string literals (including domain values like statuses, metrics, resource types, rule ids).
- **Comments**: every comment in every source file.
- **Strings**: UI labels, log messages, error messages, API responses and the LLM system/user prompts.
- **Data**: `data/` JSON files — keys and content (titles, names, notes, summaries).
- **Documentation**: every `.md` file (README, docs/, data/README).
- **Git**: commit messages, branch names (`<type>/<short-description>`, kebab-case English) and pull request titles/bodies.

Never introduce Spanish (or any other language) text in code, docs, data or git artifacts. If you find legacy non-English text anywhere, translate it to English in the same change.
