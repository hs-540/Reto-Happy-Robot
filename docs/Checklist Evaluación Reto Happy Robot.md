# Checklist — Reto Happy Robot (HackSpain 2026)

> Objetivos extraídos de `Guía del Reto Happy Robot.md` (requisitos de entrega y criterios de evaluación).

## Requisitos obligatorios de entrega

- [ ] **Sistema agéntico** — decide y actúa por su cuenta (no chatbot pasivo)
- [ ] **Escenario dinámico** — cambios continuos durante la ejecución
- [ ] **Respuesta multi-paso** — cadena de acciones con objetivo cohesivo
- [ ] **Interacción real** — integración con sistemas externos (llamadas, APIs, tickets)
- [ ] **Interfaz de usuario** — panel con estado, acciones del sistema e intervención

## 🧠 Decisión

- [ ] Decide con sensatez **sin información completa**
- [ ] Prioriza correctamente bajo **urgencia múltiple**
- [ ] Se **adapta** a cambios situacionales en vivo

## ⚡ Acción

- [ ] Coordina **simultáneamente** personas, información y recursos
- [ ] **Ejecuta de verdad** (no solo propone acciones)

## 👁 Supervisión

- [ ] **Transparencia operacional** + intervención humana posible
- [ ] Escenario y gestión **originales**
- [ ] **Aprendizaje iterativo** de ejecuciones previas

## 🎁 Bonus / Presentación

- [ ] **Aprendizaje** — análisis de ejecuciones previas para mejora continua (bonus)
- [ ] **Demo pulida** — "la demo cuenta tanto como el sistema"
